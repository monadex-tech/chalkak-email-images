# Chalkak email images

Images used in Chalkak Studio newsletters, sent through Brevo.
Each image is copied into Brevo's image library before an email goes out, so the email itself loads them from Brevo.

## Layout

One folder per newsletter, numbered to match the local `9 Newsletters` folders:

| Folder | Newsletter | Date |
|---|---|---|
| `02-cos-launch/` | COS launch | October 2026 |

Add the next issue as `03-<short-name>/`, `04-<short-name>/`, and so on.
Only put images in here that are fine to be public: they go out in emails anyway.
